# Prefade — public site

The privacy policy, terms of use and support page for the **Prefade**
app, served by GitHub Pages at
<https://simonsaucy.github.io/prefade/>.

Deliberately a separate, **public** repository:

- Apple requires these reachable without a login, and GitHub Pages does not
  serve a private repo on the free plan.
- The app source stays private.
- `prefade-library`, which holds mix data and is shared with people who
  run shows, stays private and stays out of this.

Pages: [privacy](privacy.md) · [terms](terms.md) · [support](support.md)

Edit the markdown, push, and the site updates.
